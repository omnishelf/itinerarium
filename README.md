# Itinerarium

One list for a whole trip.

**→ [omnishelf.github.io/itinerarium](https://omnishelf.github.io/itinerarium/)**

A trip planner that is one flat scroll: every day, every booking, every photograph in a single list you thumb through, instead of a tab per category. It installs to a phone's home screen and runs from there.

Everything lives in the browser on the device you installed it on. There is no account, no server, and no network call after the first load: trips are held in IndexedDB and photographs in the origin's private file system, so the app works on a plane and a trip never leaves the phone. Backups are yours to take and to carry, as a zip you export and re-import.

This repository holds the built site, which is what GitHub Pages serves.
